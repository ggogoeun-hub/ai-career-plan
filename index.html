📅 4단계 학습 로드맵

기초 역량 구축부터 실전 취업까지, 단계별로 체계적으로 진행합니다.

Phase 1 1~3개월

🔢 기초 역량 구축 — Python · 수학 · 통계

AI/ML의 토대가 되는 Python 프로그래밍, 선형대수, 확률·통계를 집중적으로 학습합니다. 데이터 분석 라이브러리(Pandas, NumPy, Matplotlib)를 익히고 첫 번째 데이터 분석 프로젝트를 완성합니다.

Python 3 NumPy / Pandas 선형대수 · 미적분 확률 · 통계 EDA 프로젝트 ×2 SQL 기초
Phase 2 4~6개월

🤖 머신러닝 핵심 알고리즘 마스터

Scikit-learn을 활용한 지도·비지도 학습, 앙상블 기법, 모델 평가 및 튜닝을 학습합니다. Kaggle 대회에 참여하여 실전 감각을 키우고, 첫 번째 ML 포트폴리오 프로젝트를 GitHub에 공개합니다.

Scikit-learn XGBoost / LightGBM Feature Engineering Kaggle 대회 참여 Google ML Crash Course ML 프로젝트 ×2
Phase 3 7~9개월

🧠 딥러닝 · LLM · 생성형 AI

PyTorch/TensorFlow로 딥러닝 기초를 다지고, Transformer 아키텍처와 LLM 파인튜닝을 학습합니다. RAG 파이프라인, LangChain, OpenAI API를 활용한 AI 애플리케이션을 개발합니다.

PyTorch Transformer / BERT / GPT LangChain / RAG OpenAI API AI 앱 개발 ×2 Hugging Face 수료
Phase 4 10~12개월

🚀 MLOps · 포트폴리오 완성 · 취업 준비

Docker, FastAPI, AWS/GCP를 활용한 모델 배포와 MLOps 파이프라인을 구축합니다. 캡스톤 프로젝트를 완성하고, 이력서·포트폴리오 사이트를 정비하여 AI 엔지니어/ML 엔지니어 포지션에 지원합니다.

Docker / FastAPI AWS SageMaker / GCP Vertex 캡스톤 프로젝트 AWS ML Specialty 포트폴리오 사이트 이력서 · 면접 준비
